# Changelog

Все заметные изменения проекта TaskFlow документируются здесь по стандарту [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] — 2024-10-25
### Added
- Реализована система авторизации (JWT-токены).
- Добавлен Dockerfile и docker-compose.yml для контейнеризации приложения.
- Подготовлены инструкции и скрипты для деплоя.

### Changed
- Обновлена структура проекта для поддержки масштабирования.
- Переработаны эндпоинты API с учётом требований безопасности.

## [0.2.0] — 2024-09-15
### Added
- Реализован полный CRUD для задач: создание, чтение, обновление, удаление.
- Добавлены валидации входных данных для всех методов API.
- Внедрены базовые HTTP-коды ответов (200, 201, 400, 404, 500).

### Fixed
- Исправлена ошибка при получении списка задач с пустым результатом.
- Устранена проблема с некорректным обновлением статуса задачи.

## [0.1.0] — 2024-08-10
### Added
- Инициализирована базовая структура проекта.
- Настроен Flask-сервер и подключение к SQLite через SQLAlchemy.
- Созданы основные маршруты и базовая логика обработки запросов.
- Подготовлен файл README.md и базовая документация.
