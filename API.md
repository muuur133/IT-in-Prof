# API — TaskFlow

Базовый URL: `http://127.0.0.1:5000`

Все запросы и ответы используют формат JSON.
Заголовок `Content-Type: application/json` обязателен для методов с телом запроса.

---

## Авторизация

### POST /auth/register — Регистрация пользователя

**Тело запроса:**
```json
{
  "username": "alice",
  "email": "alice@example.com",
  "password": "secret123"
}
```

**Ответ (201 Created):**
```json
{
  "message": "Пользователь успешно зарегистрирован",
  "user": {
    "id": 1,
    "username": "alice",
    "email": "alice@example.com"
  }
}
```

**Возможные ошибки:**
- `400 Bad Request` — пользователь с таким email уже существует.
- `400 Bad Request` — некорректные данные (пустые поля, слабый пароль).

---

### POST /auth/login — Вход в систему

**Тело запроса:**
```json
{
  "email": "alice@example.com",
  "password": "secret123"
}
```

**Ответ (200 OK):**
```json
{
  "message": "Авторизация успешна",
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "alice",
    "email": "alice@example.com"
  }
}
```

**Возможные ошибки:**
- `401 Unauthorized` — неверный email или пароль.

> После авторизации все запросы к эндпоинтам задач должны содержать заголовок:
> `Authorization: Bearer <access_token>`

## Задачи

### GET /tasks — Получить список всех задач

**Параметры запроса (опциональные):**
| Параметр | Тип | Описание |
|----------|------|----------|
| `page` | int | Номер страницы (по умолчанию 1) |
| `per_page` | int | Кол-во задач на страницу (по умолчанию 10) |

**Ответ (200 OK):**
```json
{
  "tasks": [
    {
      "id": 1,
      "title": "Изучить Flask",
      "description": "Прочитать документацию",
      "completed": false,
      "created_at": "2024-08-10T12:00:00",
      "updated_at": "2024-08-10T12:00:00"
    },
    {
      "id": 2,
      "title": "Написать API",
      "description": "Реализовать CRUD для задач",
      "completed": true,
      "created_at": "2024-08-11T09:30:00",
      "updated_at": "2024-08-12T15:20:00"
    }
  ],
  "total": 2,
  "page": 1,
  "per_page": 10
}
```

---

### POST /tasks — Создать новую задачу

**Тело запроса:**
```json
{
  "title": "Купить продукты",
  "description": "Молоко, хлеб, яйца",
  "completed": false
}
```

**Ответ (201 Created):**
```json
{
  "id": 3,
  "title": "Купить продукты",
  "description": "Молоко, хлеб, яйца",
  "completed": false,
  "created_at": "2024-08-13T10:15:00",
  "updated_at": "2024-08-13T10:15:00"
}
```

**Возможные ошибки:**
- `400 Bad Request` — отсутствует обязательное поле `title`.

---

### GET /tasks/{id} — Получить задачу по ID

**Параметры пути:**
| Параметр | Тип | Описание |
|----------|------|----------|
| `id` | int | Идентификатор задачи |

**Ответ (200 OK):**
```json
{
  "id": 1,
  "title": "Изучить Flask",
  "description": "Прочитать документацию",
  "completed": false,
  "created_at": "2024-08-10T12:00:00",
  "updated_at": "2024-08-10T12:00:00"
}
```

**Возможные ошибки:**
- `404 Not Found` — задача с указанным ID не существует.

---

### PUT /tasks/{id} — Обновить задачу

**Параметры пути:**
| Параметр | Тип | Описание |
|----------|------|----------|
| `id` | int | Идентификатор задачи |

**Тело запроса:**
```json
{
  "title": "Изучить Flask и SQLAlchemy",
  "description": "Прочитать документацию и написать мини-проект",
  "completed": true
}
```

**Ответ (200 OK):**
```json
{
  "id": 1,
  "title": "Изучить Flask и SQLAlchemy",
  "description": "Прочитать документацию и написать мини-проект",
  "completed": true,
  "created_at": "2024-08-10T12:00:00",
  "updated_at": "2024-08-13T11:45:00"
}
```

**Возможные ошибки:**
- `404 Not Found` — задача не найдена.
- `400 Bad Request` — некорректные данные в теле запроса.

---

### DELETE /tasks/{id} — Удалить задачу

**Параметры пути:**
| Параметр | Тип | Описание |
|----------|------|----------|
| `id` | int | Идентификатор задачи |

**Ответ (200 OK):**
```json
{
  "message": "Задача успешно удалена",
  "id": 1
}
```

**Возможные ошибки:**
- `404 Not Found` — задача не найдена.

---

## Коды ответов

| Код | Значение |
|-----|----------|
| 200 | Запрос выполнен успешно |
| 201 | Ресурс создан |
| 400 | Некорректный запрос |
| 401 | Не авторизован |
| 404 | Ресурс не найден |
| 500 | Внутренняя ошибка сервера |
